# My Diary App

Java Swingで作った日記アプリです。
日付ごとの日記を管理でき、カレンダー表示や保存機能があります。

---

## アプリ概要
- 日付ごとに日記を入力・保存可能
- データはローカルファイルに保存される
- シンプルで直感的なGUI設計

---


## 工夫した点
- SwingのJTableを使用してカレンダー表示 → 日記の有無を視覚的に把握可能
- ファイル保存機能を独自実装 → データの永続化を簡単に
- MVCパターンで設計 → GUIとロジックを分離して保守性向上
- 簡単操作を意識したレイアウト配置 → 初めてのユーザーでも迷わないUI

---

## 技術スタック
- Java 20以上
- Swing (GUI)
- ファイル入出力 (日記データの保存)

---

## ビルド・実行方法

### IDEでの実行
1. リポジトリをクローン
git clone https://github.com/ka-123-12/diaryapp
2. IntelliJ IDEA または Eclipse でプロジェクトを開く
3. `Main.java` を実行

### コマンドラインでの実行
1. リポジトリをクローン
git clone https://github.com/ka-123-12/diaryapp
2. プロジェクトディレクトリへ移動
cd my-diary-app
3. コンパイル
javac -d out src/*.java
4. 実行
java -cp out Main
